# 🚀 ReachInBox – Email Scheduling & Outreach Platform

A full-stack email outreach platform inspired by ReachInbox, built with **React, Node.js, Express, MongoDB, Redis, BullMQ, and Ethereal Email**.

The application allows users to log in, create email campaigns, schedule emails, and manage outreach through a dashboard. The backend uses **BullMQ + Redis** for reliable background job processing, scheduling, concurrency, and rate limiting.

🔗 **Live Frontend:** https://naveendot55.github.io/ReachInBox/
